Descrição:  
Crie uma função que receba um nome como parâmetro e exiba uma mensagem de boas-vindas.

Definição de função com parâmetro.

Entrada:  
Um nome.

Saída:  
Mensagem personalizada.

## Exercício 094 - Organização de programa com funções

Descrição:  
Crie um programa que utilize pelo menos duas funções diferentes:

-   uma para entrada de dados
    
-   outra para processamento
    

O programa deve calcular a média de notas.

Foco:  
Separação de responsabilidades.

Entrada:  
Notas do usuário.

Saída:  
Média calculada.
