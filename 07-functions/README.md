# 07 - Functions

Neste módulo você aprenderá a organizar melhor seu código utilizando **funções**.

Funções permitem dividir o programa em partes menores, facilitando leitura, reutilização e manutenção.

---

## O que você vai aprender

Neste módulo, o foco é entender funções:

-   Definição de funções (`def`)
    
-   Parâmetros e argumentos
    
-   Retorno de valores (`return`)
    
-   Reutilização de código
    
-   Uso de funções nativas da linguagem
    

---

## Objetivo

O objetivo é aprender a:

-   organizar melhor o código
    
-   evitar repetição
    
-   criar blocos reutilizáveis
    

---

## Estrutura

Os exercícios estão divididos em três níveis:

-   `easy` → funções simples
    
-   `medium` → funções com parâmetros
    
-   `hard` → organização de programas com múltiplas funções
    

---

## Recomendações importantes

-   Crie funções com responsabilidades claras
    
-   Evite funções muito grandes
    
-   Use nomes descritivos
    
-   Teste funções separadamente
    

---

## Dicas

-   Comece com funções pequenas
    
-   Pense no que entra e no que sai da função
    
-   Use `return` sempre que necessário
    
-   Reutilize funções sempre que possível
