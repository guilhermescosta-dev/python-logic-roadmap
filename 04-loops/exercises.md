## Exercício 044 - Menu simples até sair

Descrição:  
Crie um programa que exiba um menu com as opções:  
1 - Mostrar mensagem de boas-vindas  
2 - Mostrar mensagem de estudo  
3 - Sair

O programa deve continuar em execução até que o usuário escolha sair.

Loop recomendado:  
`while True`

Entrada:  
Uma opção do menu por vez.

Saída:  
A ação correspondente à opção escolhida.

# Hard

## Exercício 045 - Validador de senha

Descrição:  
Defina uma senha no programa e permita que o usuário tente acertá-la. O programa deve continuar pedindo a senha até que a correta seja digitada.

Loop recomendado:  
`while True`

Entrada:  
Tentativas de senha.

Saída:  
Mensagens de erro enquanto a senha estiver incorreta e uma mensagem final quando o acesso for liberado.

---

Loop recomendado:  
`while True`

Entrada:

Saída:  
Dicas e mensagem final de acerto.

## Exercício 052 - Validação de entrada positiva

Descrição:  
Peça ao usuário um número inteiro positivo. Enquanto ele digitar um valor inválido (zero ou negativo), o programa deve continuar pedindo outro valor. Quando receber um número válido, exiba uma mensagem confirmando o valor.

Loop recomendado:  
`while`

Entrada:  
Tentativas de números até um valor positivo válido.

Saída:  
Mensagens de erro para entradas inválidas e uma mensagem final de confirmação.
