# 04 - Loops

Neste módulo você aprenderá a trabalhar com **repetição de processos dentro do programa**.

Ao invés de repetir código manualmente, você aprenderá a automatizar execuções.

---

## O que você vai aprender

Neste módulo, o foco é entender estruturas de repetição:

* Estrutura `while`
* Estrutura `for`
* Contadores
* Acumuladores
* Controle de repetição

---

## Objetivo

O objetivo é aprender a:

* repetir ações de forma controlada
* processar múltiplos dados
* automatizar tarefas dentro do código

---

## Estrutura

Os exercícios estão divididos em três níveis:

* `easy` → repetições simples
* `medium` → uso de contadores e acumuladores
* `hard` → controle mais completo de loops

---

## Recomendações importantes

* Sempre defina claramente quando o loop deve parar
* Evite loops infinitos
* Teste com diferentes valores de entrada
* Observe o comportamento em cada repetição

---

## Dicas

* Use `while` quando não souber quantas repetições serão necessárias
* Use `for` quando souber a quantidade de repetições
* Acompanhe o valor das variáveis durante o loop
* Comece com exemplos simples

---

---

## Observação

Loops são essenciais para resolver problemas reais.

Eles permitem que o programa lide com múltiplas informações de forma eficiente.
