# 01 - Basic Syntax

Este módulo é o ponto de partida da trilha.

Aqui você vai aprender como escrever programas simples em Python e entender como o código é estruturado.

---

## O que você vai aprender

Neste módulo, o foco é dominar os fundamentos básicos da linguagem:

-   Entrada de dados (`input`)
-   Saída de dados (`print`)
-   Organização básica do código
-   Sequência de execução
-   Comentários no código

---

## Objetivo

O objetivo aqui **não é lógica complexa**, mas sim:

-   se familiarizar com a linguagem
-   entender como um programa é executado
-   perder o medo de escrever código

---

## Estrutura

Os exercícios estão divididos em três níveis:

-   `easy` → primeiros contatos com código
-   `medium` → pequenos programas com múltiplos passos
-   `hard` → scripts simples mais completos

---

## Recomendações importantes

-   Não pule níveis
-   Teste seu código com diferentes entradas
-   Foque em entender o que cada linha faz
-   Evite copiar soluções prontas

---

## Dicas

-   Use nomes de variáveis simples e claros
-   Mantenha o código organizado
-   Leia seu código como se fosse outra pessoa
-   Se algo não funcionar, teste passo a passo
