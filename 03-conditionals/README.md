# 03 - Conditionals

Neste módulo você começará a trabalhar com **tomada de decisão dentro do programa**.

Aqui a lógica começa de fato: o programa deixa de ser apenas sequencial e passa a responder a diferentes situações.

---

## O que você vai aprender

Neste módulo, o foco é entender estruturas condicionais:

* Estrutura `if`
* Estrutura `if/else`
* Estrutura `if/elif/else`
* Operadores relacionais (`>`, `<`, `==`, `!=`, etc.)
* Operadores lógicos (`and`, `or`, `not`)

---

## Objetivo

O objetivo é aprender a:

* tomar decisões dentro do código
* criar regras baseadas em condições
* controlar o fluxo de execução

---

## Estrutura

Os exercícios estão divididos em três níveis:

* `easy` → decisões simples
* `medium` → múltiplas condições
* `hard` → regras mais complexas

---

## Recomendações importantes

* Leia cada condição com atenção
* Evite criar regras confusas
* Teste todos os caminhos possíveis do programa
* Sempre pense no que acontece quando a condição não é atendida

---

## Dicas

* Use indentação corretamente (isso é essencial em Python)
* Prefira condições simples e claras
* Evite aninhar muitas condições no início
* Teste diferentes cenários
