# Python Logic Roadmap

Repositório público focado no desenvolvimento da **lógica de programação utilizando Python**, com exercícios organizados por **conteúdo** e **nível de dificuldade**.

---

## Objetivo

Este projeto foi criado com o propósito de:

* Desenvolver o raciocínio lógico na programação
* Praticar resolução de problemas de forma estruturada
* Organizar estudos de forma progressiva
* Construir um portfólio técnico no GitHub
* Disponibilizar exercícios para outros iniciantes

> Este repositório é destinado a prática. Caso utilize como base, mantenha a referência ao projeto original.

---

## Estrutura do Projeto

Os exercícios estão organizados por conteúdo, seguindo uma progressão lógica:

```
01 - Basic Syntax  
02 - Variables and Data Types  
03 - Conditionals  
04 - Loops  
05 - Type Casting  
06 - Exceptions  
07 - Functions  
08 - Lists, Tuples and Sets  
09 - Dictionaries  
10 - Mixed Challenges  
```

Cada conteúdo possui três níveis de dificuldade:

* **easy** → conceitos básicos e primeiros contatos
* **medium** → aplicação prática com mais lógica
* **hard** → desafios mais completos e estruturados

---

## Como utilizar este repositório

Clone o repositório para sua máquina:
1. git clone https://github.com/guilhermescosta-dev/python-logic-roadmap.git

Depois:

2. Acesse um dos diretórios por conteúdo *(indicado seguir na ordem)*
3. Leia o arquivo `README.md` do módulo
4. Escolha um exercício de acordo com o nível
5. Desenvolva sua solução localmente
6. Teste com diferentes entradas
7. Registre seu progresso no GitHub

---

## Organização dos exercícios

Cada exercício segue um padrão:

* Enunciado claro
* Descrição de entrada e saída
* Regras e restrições
* Exemplos de uso
* Arquivo base (`starter.py`) sem solução pronta

---

## Sobre as soluções

Para manter este repositório útil para outras pessoas:

* ❌ As soluções **não ficam expostas na branch principal**
* ✅ Recomenda-se utilizar:

  * uma branch separada (`solutions`)
  * ou um repositório privado

---

## Boas práticas recomendadas

* Clareza antes de complexidade
* Consistência na organização
* Aprendizado baseado em prática
* Evitar copiar soluções prontas
* Revisar o código após funcionar
* Fazer commits frequentes e descritivos

Exemplos de commits:

```
study: resolvi o exercício easy 01  
refactor: melhorei a lógica do exercício 03
```
