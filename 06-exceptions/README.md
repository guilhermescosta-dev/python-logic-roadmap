# 06 - Exceptions

Neste módulo você aprenderá a lidar com **erros durante a execução do programa**.

Ao invés de permitir que o programa quebre, você aprenderá a tratar situações inesperadas de forma controlada.

---

## O que você vai aprender

Neste módulo, o foco é entender tratamento de exceções:

-   Estrutura `try/except`
    
-   Tratamento de erros comuns
    
-   Prevenção de falhas em tempo de execução
    
-   Uso de múltiplos `except`
    
-   Estrutura `else` e `finally` (introdução)
    

---

## Objetivo

O objetivo é aprender a:

-   evitar que o programa interrompa inesperadamente
    
-   tratar entradas inválidas do usuário
    
-   tornar o código mais robusto
    

---

## Estrutura

Os exercícios estão divididos em três níveis:

-   `easy` → tratamento de erros simples
    
-   `medium` → validação de entradas
    
-   `hard` → múltiplos cenários de erro
    

---

## Recomendações importantes

-   Nunca ignore erros sem entender o motivo
    
-   Evite usar `except` genérico sem necessidade
    
-   Teste situações inválidas intencionalmente
    
-   Pense sempre no que pode dar errado
    

---

## Dicas

-   Comece tratando erros simples, como conversão de tipos
    
-   Use mensagens claras para o usuário
    
-   Combine validação com tratamento de exceções
    
-   Mantenha o código organizado
