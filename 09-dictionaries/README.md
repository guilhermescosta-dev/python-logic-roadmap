# 09 - Dictionaries

Neste módulo você aprenderá a trabalhar com **dados organizados em formato de chave e valor**.

Dicionários são fundamentais para representar informações estruturadas de forma mais próxima de cenários reais.

---

## O que você vai aprender

Neste módulo, o foco é entender dicionários:

-   Estrutura de um dicionário (`dict`)
    
-   Criação de pares chave-valor
    
-   Acesso e modificação de valores
    
-   Inserção e remoção de dados
    
-   Percorrer dicionários
    

---

## Objetivo

O objetivo é aprender a:

-   organizar dados de forma estruturada
    
-   acessar informações de maneira eficiente
    
-   representar entidades reais no código
    

---

## Estrutura

Os exercícios estão divididos em três níveis:

-   `easy` → criação e acesso a dados
    
-   `medium` → manipulação de informações
    
-   `hard` → uso de estruturas mais complexas
    

---

## Recomendações importantes

-   Use nomes claros para as chaves
    
-   Evite estruturas confusas no início
    
-   Teste diferentes formas de acesso
    
-   Entenda como os dados estão organizados
    

---

## Dicas

-   Pense no dicionário como uma “tabela” simples
    
-   Use `.keys()`, `.values()` e `.items()`
    
-   Combine dicionários com loops
    
-   Use quando precisar relacionar informações
