# 08 - Lists, Tuples and Sets

Neste módulo você aprenderá a trabalhar com **coleções de dados**.

Isso permite armazenar e manipular múltiplos valores dentro de uma única estrutura.

---

## O que você vai aprender

Neste módulo, o foco é entender estruturas de dados básicas:

-   Listas (`list`)
    
-   Tuplas (`tuple`)
    
-   Conjuntos (`set`)
    
-   Acesso e manipulação de elementos
    
-   Percorrer coleções com loops
    

---

## Objetivo

O objetivo é aprender a:

-   trabalhar com múltiplos dados
    
-   organizar informações
    
-   manipular coleções de forma eficiente
    

---

## Estrutura

Os exercícios estão divididos em três níveis:

-   `easy` → criação e acesso a elementos
    
-   `medium` → manipulação de coleções
    
-   `hard` → uso combinado com lógica
    

---

## Recomendações importantes

-   Entenda a diferença entre lista, tupla e conjunto
    
-   Escolha a estrutura adequada para cada caso
    
-   Teste operações de inserção e remoção
    
-   Observe como os dados são armazenados
    

---

## Dicas

-   Use listas para dados mutáveis
    
-   Use tuplas para dados fixos
    
-   Use conjuntos para eliminar duplicidade
    
-   Combine coleções com loops
