# 05 - Type Casting

Neste módulo você aprenderá a trabalhar com **conversão de tipos de dados**.

Isso é fundamental para lidar corretamente com entradas do usuário e operações entre diferentes tipos.

---

## O que você vai aprender

Neste módulo, o foco é entender conversões de tipo:

-   Conversão de `str` para `int`
    
-   Conversão de `str` para `float`
    
-   Conversão de números para `str`
    
-   Uso de `int()`, `float()`, `str()`
    
-   Problemas comuns com tipos incompatíveis
    

---

## Objetivo

O objetivo é aprender a:

-   transformar dados de um tipo para outro
    
-   evitar erros causados por tipos incompatíveis
    
-   preparar dados para operações
    

---

## Estrutura

Os exercícios estão divididos em três níveis:

-   `easy` → conversões básicas
    
-   `medium` → uso prático com entrada de dados
    
-   `hard` → cenários com múltiplas conversões
    

---

## Recomendações importantes

-   Lembre que `input()` sempre retorna texto (`str`)
    
-   Sempre valide o tipo antes de usar
    
-   Evite misturar tipos sem conversão adequada
    
-   Teste diferentes entradas
    

---

## Dicas

-   Use `type()` para verificar tipos
    
-   Converta dados antes de fazer operações
    
-   Fique atento a erros de conversão
    
-   Pratique com exemplos simples
