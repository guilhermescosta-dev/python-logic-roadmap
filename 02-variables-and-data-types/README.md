# 📌 02 - Variables and Data Types

Neste módulo você começará a trabalhar com **dados dentro do programa**.

Aqui é onde a programação começa a fazer mais sentido, pois você passa a armazenar, manipular e utilizar informações.

---

## O que você vai aprender

Neste módulo, o foco é entender como os dados funcionam em Python:

* Criação de variáveis
* Tipos de dados (`int`, `float`, `str`, `bool`)
* Atribuição de valores
* Operações básicas com variáveis
* Exibição de valores

---

## Objetivo

O objetivo é aprender a:

* armazenar informações dentro do programa
* manipular valores
* entender como os dados são tratados pela linguagem

---

## Estrutura

Os exercícios estão divididos em três níveis:

* `easy` → criação e uso básico de variáveis
* `medium` → manipulação de dados e operações
* `hard` → pequenos problemas com múltiplas variáveis

---

## Recomendações importantes

* Sempre identifique o tipo de dado que está usando
* Cuidado com misturar tipos diferentes sem entender
* Teste operações com números e textos
* Observe como o Python trata cada tipo

---

## Dicas

* Use nomes de variáveis descritivos (ex: `idade`, `nome`, `total`)
* Evite nomes genéricos como `x` e `y` no início
* Teste imprimir o tipo usando `type()`
* Preste atenção em como o Python trata strings e números
